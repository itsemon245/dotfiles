# Phase 2 Shell Inventory

Captured during Phase 2 while introducing `tools/.local/bin`,
`tools/.local/lib/dotfiles/shell`, and the later Python tool runtime.

## Classification

| Class | Files |
| --- | --- |
| `sourced-startup` | `zsh/.zshrc`, `zsh/exports.sh`, `zsh/ssh-agent.sh` |
| `sourced-library` | `zsh/zsh_utils/helpers.sh`, `zsh/aliases/*.sh`, `tools/.local/lib/dotfiles/shell/*.sh` |
| `portable-tool` | `tools/.local/bin/disk-free`, `download_speed`, `memory`, `php`, `composer`, `sysphp`, `zstd-compress`, `zstd-extract` |
| `desktop-tool` | `tools/.local/bin/wally`, `rofi-vpn`, `rofi-cast`, `rofi-monitor`, `barr`, `brightness`, `brightness-adjust`, `cliphist-rofi`, `readable-window`, `hypr-startup` |
| `installer-helper` | `install.sh`, `stow.sh`, `pocman/bin/pocman`, `mac_setup.sh`, `mac_install_packages.sh`, `nvm-setup.sh`, `zsh-setup.sh`, `scripts/check-dotfiles` |
| `desktop-config script` | Hyprland startup scripts, Ironbar state scripts, Rofi applet/launcher scripts, OpenRGB/Wallust/SDDM helper scripts |
| `excluded or deferred` | `zsh/.oh-my-zsh`, `tmux/tmux-installer`, `omarchy` scripts and other vendored/third-party content |

## Duplicated Behavior Found

- PATH mutation and duplicate prevention in shell startup files.
- Guarded sourcing for optional startup files and alias directories.
- Optional command checks in executable tools.
- Notification adapters around `dunstify` and `notify-send`.
- Usage/error handling in desktop tools.
- Docker setup shared by the PHP and Composer wrappers.
- Legacy command locations under `~/bin`, `~/env/bin`, and app config script paths.

## Phase 2 Decisions

- `tools/.local/bin` is the canonical home for maintained first-party commands.
- Known call sites use `tools/.local/bin` directly; old package-local command wrappers were removed.
- Startup-safe helpers live in `tools/.local/lib/dotfiles/shell`.
- Maintained executable-tool helpers live in `tools/.local/lib/dotfiles_py/dotfiles_tools`.
- The transitional Bash executable-tool helper layer under `tools/.local/lib/dotfiles/tool` was removed.
- Rofi applet packs, Omarchy, Oh My Zsh, and tmux installer content are not migrated in this phase unless they become directly maintained first-party tools.
